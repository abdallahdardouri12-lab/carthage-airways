# ============================================================
#  Carthage Airways - organisation des fenetres par role
#  [nom_de_la_fenetre | Titre - Sous-titre]
#  Nom de l'onglet = fenetre d'origine
#    @tableau = tableau de bord automatique
#  Garder seulement certains sous-onglets d'une fenetre :
#    fenetre [avec: mot]   -> garde les sous-onglets dont le titre contient "mot"
#    fenetre [sans: mot]   -> enleve les sous-onglets dont le titre contient "mot"
#  Plusieurs fenetres dans un onglet : Titre: fenetre + Titre: fenetre
#  Les fenetres non citees restent des fenetres separees
#  (connexion, espace personnel navigant, ajouter, modifier,
#   supprimer, annulation, carte d'embarquement...).
# ============================================================
